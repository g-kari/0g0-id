# プロフィール初回読み込みの復旧（2026-10-02）

`/profile` で `/api/me` の取得に失敗した場合、画面を空白にせず、エラー内容と
「もう一度読み込む」ボタン、トップへのリンクを表示します。エラーは自動消去せず、
スクリーンリーダーにも通知します。読み込み中は説明付きの状態を表示します。

再試行はボタンを押したときだけ行い、通信中の連打による重複リクエストを防ぎます。
再試行に成功すると従来のプロフィール・編集フォーム・アカウント操作へのリンクを表示し、
名前欄にフォーカスを移します。再失敗時は再試行ボタンにフォーカスを戻します。
初回読み込みではフォーカスを移しません。成功後は追加の読み込みを行わず、入力中の
編集内容を上書きしません。

初回読み込みの修正ではAPI、認証リダイレクト、セッション、保存・削除・ログアウト処理は変更していません。
自動再試行、追加の依存パッケージ、マイグレーションもありません。

## 確認

- 初回成功、初回通信失敗、繰り返しの失敗、明示的な再試行からの復旧
- 通信中の重複読み込み・連打の抑止、成功後の入力保持
- エラー文字列の安全なテキスト表示、汎用エラー時の日本語表示
- エラー・読み込み状態、キーボードフォーカス、復旧後の既存リンク

テストは合成データのみを使用し、本番のプロフィール取得やアカウント更新は行いません。

CI では、ビルドしたプロフィール画面を使い捨ての localhost サーバーで配信し、
Playwright `1.57.0` で 320px / 1280px の表示と操作を確認します。
`/api/me` は決められた合成レスポンスのみを返し、外部通信と実API書込を遮断します。下記の保存回帰ケースだけは、正確なfixture originのプロフィールPATCHをブラウザー内で捕捉して合成応答を返します（サーバーに書込ルートはありません）。
初回成功、通信・HTTP エラー、連打、キーボード再試行、復旧後のナビゲーション、
既存の 401 リダイレクトを検証し、結果と画面を `profile-recovery-ui` artifact に保存します。
Playwright は CI の一時ディレクトリにのみインストールし、アプリの依存には追加しません。

## CI audit のリリース阻害への対応

2026-10-01 の audit で、既存の devalue `5.8.1` に high の advisory が報告されました。
user / admin frontend の override と lockfile の devalue だけを、公式修正版 `5.9.3` に更新します。
Astro `7.2.8` が指定する `^5.8.1` の範囲内で、他の依存や Node 要件、API、認証処理は変更しません。
audit の閾値は維持します。

本リポジトリは静的 Astro 出力を使い、devalue の直接呼び出しやコンテンツローダー、
Astro Actions / SSR セッションはありません。本番プロフィール入力から当該処理への
攻撃経路は確認していませんが、脆弱な依存を残してリリースすることは避けます。
繰り返し文字列の出力増幅、非文字列の null-prototype キー、通常のシリアライズを
小さな合成入力で比較し、audit・全テスト・両 frontend ビルド・最終コミットの CI を確認します。

根拠: [high advisory](https://github.com/advisories/GHSA-mcm9-63f2-9j32)、
[公式 5.9.3 リリース](https://github.com/sveltejs/devalue/releases/tag/v5.9.3)。

## 保存中の追加入力の保持（2026-10-19）

保存ボタンを押した時点の値を固定して送ります。応答が返るまでに編集した欄はそのまま保持し、未編集の欄には従来どおりサーバーで正規化した値を反映します。上部の名前・画像は応答で確認した保存済みプロフィールです。現在の入力が応答と異なる場合は「保存中に編集した内容は未保存」と案内を残し、次の明示的な保存でその値を送ります。編集した値がすでに確認済みの値と同じなら未保存とは表示しません。

保存中の連打は一つのリクエストにまとめ、成功後の自動再送はしません。失敗時は現在の入力を保持し、保存ボタンで明示的に再試行できます。保存完了後の入力では以前の成功表示を残さず、保存操作を案内します。認証・APIの入力契約・アカウント削除・ログアウト・依存・CI設定は変更していません。同じプロフィールページ内の保護であり、別タブ・別端末の同時更新を調停する機能ではありません。

回帰は実ページと保存処理の合成DOM、およびビルド済みページの390px/1280px Chromiumで確認します。保存中に4欄を編集→旧応答後も保持→次の保存で新値を送信、無追加入力の正規化、HTTP失敗→保持→再試行、連打・キーボード・フォーカスと未保存案内を確認します。名前/電話/住所/画像URLはすべて架空のfixtureです。本番アカウントや認証情報は使いません。
