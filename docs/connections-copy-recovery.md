# 連携サービスの Sub ID コピー復旧

連携サービス画面の既存「コピー」操作が使えない端末でも、同じ表示値を手動でコピーできます。失敗時にだけ「Sub ID（手動コピー用）」の読み取り専用欄が現れます。コピー操作からフォーカスを移していなければ値全体を選択します。別の場所へ移動済みならフォーカスを奪いません。端末の通常のコピー操作を使ってください。

成功時はコピー成功、失敗時は失敗と明示します。追加のクリップボード権限要求や権限設定変更、非表示の自動再試行、認証・サービス解除API変更はありません。値は従来から表示していた Sub ID のみです。これはデータ消失の修正ではなく、クリップボード失敗からの可視回復です。

## 検証

既存 `vp check` / `vp test run`、型CLI/API docs同期、user/admin buildを実行します。合成DOMの成功・NotAllowedError・未提供・連打・後からの明示再試行・フォーカス移動をテストします。正常CI内の既存固定Playwright1.57.0環境で `scripts/connections-copy-browser-smoke.mjs` を実行し、390/1280pxの8ケース（成功・拒否・未提供・遅延失敗と行別再試行）・実画像を確認します。fixtureは合成IDのGETだけで、POST/DELETEを遮断し追加権限は付与しません。実ユーザーや本番APIは使いません。

## 変更履歴

- コピー失敗を未処理Promiseのままにせず、同じ値のreadonly選択欄とlive statusを提示。通常コピー成功とサービス解除の契約は不変。
