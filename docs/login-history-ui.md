# ログイン履歴の読み込み・復旧改善

## 変更内容（2026-10-03）

- 初回・追加の読み込みに失敗した際、画面内の「もう一度読み込む」から再試行できます。
- 追加読み込みの失敗時は、既に表示している履歴と次の取得位置を維持します。
- プロバイダーを切り替えた場合、古いリクエストを中断し、その応答で新しい一覧が上書きされることを防ぎます。
- ボタンの連打で同じページを重複取得しません。読み込み中・表示件数・末尾・空の結果を区別して表示します。
- エラーと読み込み状態を支援技術へ通知し、再試行後や末尾ではキーボード操作を続けられるようフォーカスを復元します。

既存の GET API とセッション切れ時のログイン画面への遷移を使用します。

## 検証

- `vp test run` と `vp check`
- user / admin の frontend build
- `scripts/login-history-browser-smoke.mjs` による実際のビルド成果物の検証
  - 320px / 1280px 幅で初回失敗・再試行・再失敗・復旧
  - 追加失敗・同一 offset の再試行・連打抑制・末尾のフォーカス
  - 素早いフィルター変更・古い応答・空の結果・戻る操作
  - ネットワーク障害、既存の 401 リダイレクト

ブラウザ検証は合成データの GET 応答だけを使用し、外部オリジンと書き込みを遮断します。
実アカウントでのログイン・変更・削除を行いません。CI は Playwright 1.57.0 の Chromium を使用します。
